Overview

SoulX-Transcriber: End-to-End Multi-Speaker Diarization and Recognition Model.

SoulX-Transcriber is an end-to-end Speech LLM for timestamped speaker-attributed ASR. The model iteratively analyzes global audio structure, predicts temporal boundaries, and performs fine-grained segment analysis.

🔄

Agentic Multi-Turn Reasoning

Iterative global-to-local inference: global speaker summary → boundary prediction → fine-grained segment decoding.

🧠

Speaker-Aware Context Cache

Extends processing to long-form audio beyond the training context window while preserving speaker consistency.

📈

Three-Stage Progressive Training

Multi-task foundation → temporal interaction learning → cache-conditioned decoding for robust performance.

🏆

State-of-the-Art Performance

Outperforms strong baselines including closed-source Gemini-2.5-Pro on AliMeeting and AISHELL-4.
